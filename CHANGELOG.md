# Changelog

All notable changes to the `stalar` skills are documented here. Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versioning follows [SemVer](https://semver.org/).

## [1.0.1] - 2026-10-01

### Fixed
- Skill descriptions are quoted, so `npx skills add` reads every skill.

## [1.0.0] - 2026-10-01

### Added
- `stalar-setup`, plus eleven skills in three groups: prospecting and lead generation (`prospecting`, `lead-lists`, `find-contacts`, `account-research`), outbound (`outreach-sequence`, `cold-outreach`, `outreach-results`) and daily selling (`sales-briefing`, `meeting-prep`, `meeting-follow-up`, `email-replies`).
